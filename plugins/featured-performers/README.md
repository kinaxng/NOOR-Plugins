# 精选女优 0.7.0：作者剧集库

入口：侧栏「精选女优」。首页是作者卡片；点击进入背景图、透明 LOGO、简介和横版作品墙。

## 常用流程

1. 添加作者并选择现有 CD2 作者目录。已有绑定直接保留。
2. 在作者右上角「作者设置」编辑资料，上传海报、背景、透明 LOGO；每种图片也可从外链导入，实际文件写入 CD2。
3. 作者目录下每个达到大小门槛的视频就是一部作品，子目录中的视频汇总为横版卡片；不把文件夹当作品。默认 ≥100 MB（1 MB = 1024² 字节），首页或作者页「作品筛选」可调整，全插件生效。没有年份也能编辑。
4. 卡片显示 NFO 的标题；没有 NFO 时显示原文件名（不含扩展名）。打开卡片编辑 NFO 标题、标签、演员、片商、简介和发布日期。外部来源是可选辅助；未匹配也可保存。来源封面经服务端代理获取，不把网络候选当成已保存封面。
5. 日常保存仅写入原文件同名的 NFO 和所选封面，不改名或移动视频。需要让 Emby 按“作者＝电视剧、年份＝季、作品＝集”读取时，使用作者页「整理 Emby」单独预览并执行目录整理。

## Emby 剧集布局

- 「整理 Emby」把正片及其同名 NFO、`-thumb` 封面移动至作者根目录下的年份季目录，如 `Season 2025`；没有明确年份时使用 `Season 01`，`season.nfo` 标题为“未指定年份”。作者根目录写入 `tvshow.nfo`，作品 NFO 使用 `episodedetails`。
- 年份只来自已有年份绑定或文件名中的明确完整日期，不从 网盘修改时间猜测。作品 NFO 缺少发布日期、厂商时，可从文件名中的明确日期及麻豆传媒、糖心、果冻传媒、精东影业、天美传媒等已知标记补全；演员名不会误当成厂商，编辑器仍可手动修改。
- 已有集号保持不变，新作品只追加编号。后补历史年份不会重排已有编号。
- 同一原目录存在达到门槛的正片时，该目录内低于门槛的小视频才作为广告候选；明确广告／地址文本和快捷方式也列入候选。执行前展示完整清单并二次确认，执行后直接从 CD2 删除，不生成恢复备份。
- 同名目标冲突会阻止执行。批量任务逐项记录状态，中断后可用同一预览重试未完成项。完成仅表示 CD2 写入成功，仍需更新挂载缓存并重新扫描 Emby。

## NFO 标题与匹配

- 没有 NFO 标题时，编辑器提供从文件名提取的建议；已有 NFO 标题不自动重洗。「从原文件名提取标题」可重新生成建议，保存前不会写入远端。
- 去除发行网址、开头的完整日期、分隔明确的作者名前后缀和画质噪音；保留集数、上下部、番外、年份故事名等内容。AI 增强、4K60 帧等提取为标签，不根据文件名日期或修改时间填写发布日期。清洗是规则式建议，歧义标题可手动修正。
- 打开编辑器按 NFO 标题匹配已缓存来源。手动修改后可点击「按当前 NFO 标题匹配」；不再用原文件名的高相似度覆盖 NFO 的匹配依据。候选需要用户明确采用，不自动覆盖 NFO 或图片。
- NFO 标题按远端文件标识、SHA1、大小和更新时间持久缓存；只为可见卡片按需读取，目录版本变化后局部失效。解析错误显示原因，不覆盖损坏的 NFO。
- 来源作品库、标题匹配结果及来源封面均持久缓存。匹配只在 NOOR 本地执行，封面在展开候选时按需获取，预览和保存复用同一份文件；手动重新抓取来源后重新校验对应缓存，不因打开页面或修改字段重抓网站。

年份目录按需绑定到稳定季号，补入历史年份不重排；年份资料和图片在「年份设置」。未指定年份作品使用既有虚拟分组，保留已有编号。目录排序不改变季集号。

## 安全和状态

作者作品页右上角「清理垃圾」仍用于通用杂项的可恢复清理，默认筛选 2 MB 以内的广告文本、网页／系统快捷方式和系统杂项。小广告视频的识别与永久删除属于「整理 Emby」，要求同目录先有达到作品门槛的正片。

清单可逐项取消勾选，确认后串行执行远端备份和删除；清理记录支持恢复且拒绝覆盖同名文件。原文件位置或内容变化时停止，备份失败不删除。大小是筛选上限，不是判断垃圾的唯一条件。此功能清除作品目录中的杂项，但保留远端备份，因此不释放备份占用的空间。未提供自动定时清理或永久清空备份。

清理和恢复提交后由后台完成当前文件，页面通过短请求查询备份、删除和确认阶段，不受单次页面请求 30 秒限制。断线不等于失败，不会自动重复提交；刷新页面后可在「清理记录」查看进行中任务。关闭页面或停止后续处理不会撤回已经提交的当前项，但不会继续提交剩余文件。服务重启后的未确认结果需要核对记录，不自动重试删除。

- 目录/封面按需读取；图片只为可见卡片加载，并发上限 2；浏览和编辑输入不会扫描全盘或下载视频。
- 文件写入仍复用 CD2 适配器、临时上传确认、远端备份和失败恢复。旧 PNG 封面保持 PNG；上传替换时真实转码。
- 保存前校验 NFO 内容版本、目标冲突及文件位置。失败保留表单，可重试；外部修改需重新读取。
- 解绑不删除任何远端文件。作者卡片无图片时显示占位，不生成假封面或假 LOGO。
- 「CD2 保存成功」不代表 Emby 已刷新。本插件不生成 STRM。
- 仅在首次打开作者时分批索引其绑定目录及子目录，每请求最多读取一页 500 条远端目录信息；排除隐藏目录和备份，不扫描整个网盘。缺少背景/LOGO 时需用户在作者设置补充。

## 长期缓存与目录变更

- 列表、海报、背景、透明 LOGO 和作品封面持久保存到插件私有数据目录，不因 5 分钟到期或服务重启重新访问 CD2/115；同一浏览器会话返回作者先显示列表快照，再查询本地索引。
- 精选女优内置 CD2 目录缓存服务（`services/directory_changes.py`），不使用会触发 STRM/刮削的任务发现监控。不同消费者独立读取目录版本，不互相确认或抢走事件。
- NOOR 经 CD2 Client 成功上传、复制、改名、移动、删除及离线完成后，标记涉及的订阅目录；短暂合并后更新。外部 App/网页修改使用低频目录分页校验，并非官方实时推送。
- 首页/作者页「作品筛选」可设兜底检查间隔，默认 0（完全缓存、关闭周期轮询），也可设置 15～10080 分钟的低频兜底检查。CD2/Emby 或 NOOR 写入事件只刷新发生变化的目录；页面、标题和封面读取均使用本地持久缓存，手动「刷新缓存」才执行完整远端核对。
- 页面每 30 秒只读 NOOR 本地目录版本；发现变化后局部更新，不全盘重扫，不覆盖打开的编辑表单。子目录改名同步路径，删除子目录移除其缓存作品，保留绑定元数据。手动「刷新作品」仍可全量核对作者目录。
- 查询或图片获取失败保留旧缓存；目录检查指数退避，风控至少冷却一小时。手动保存 NFO 仍执行远端冲突校验，不使用缓存代替写入安全检查。
- 缓存目前不自动回收旧图片；外部变更不是即时通知。文件操作及缓存沿用 NOOR 当前单个 CD2 存储连接，不引入 Cookie、CloudDrive 或挂载依赖。
