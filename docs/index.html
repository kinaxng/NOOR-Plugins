GET STARTED

接入 SDK

插件入口的 mount(root, sdk) 会收到当前 NOOR 提供的完整能力。

export async function mount(root, sdk) {
  const enabled = sdk.ui.settingsSwitch({ checked: true })
  const row = sdk.ui.settingRow({
    label: '启用功能',
    description: '说明该选项影响的行为。',
    control: enabled,
  })
  root.append(sdk.ui.settingsCard({ title: '基础设置', children: [row] }))
}

COMPONENTS

组件

以下预览使用文档站的镜像主题；生产插件必须调用对应的 sdk.ui API。

Button

用于动作、提交和次要操作。

sdk.ui.button({ label: '保存', tone: 'primary', onClick: save })

Tag / Badge

Tag 表达分类，Badge 表达状态或可操作筛选。

信息已完成等待中12 项
sdk.ui.tag({ label: '已完成', tone: 'success' })
sdk.ui.badge({ label: '12 项' })

Tooltip

为图标和短操作提供补充说明，支持悬停与键盘焦点。

刷新当前插件数据
sdk.ui.tooltip({ trigger, text: '刷新当前插件数据' })

Dropdown / Menu

紧凑承载一组关联动作，并提供菜单语义和 Escape 关闭。

sdk.ui.dropdown({ trigger, items: [{ label, value, onClick }] })

Progress

展示下载、处理和同步进度，并通过 ARIA 暴露当前值。

68%
sdk.ui.progress({ value: 68, tone: 'info' })

Checkbox / Radio

多项选择使用 Checkbox，互斥选择使用同名 Radio。

sdk.ui.checkbox({ label: '生成 MediaInfo', checked, onChange })
sdk.ui.radio({ label: '自动模式', name: 'mode', value: 'auto' })

Alert

展示需要保留在当前上下文中的提示、成功、警告和错误。

请求已降速检测到服务限流，后台任务将在稍后继续。
sdk.ui.alert({ tone: 'warning', title: '请求已降速', message })

Empty / Loading

为空数据和等待状态提供一致的反馈，也可以附加下一步操作。

暂无离线工程新建云下载或从云端目录选择文件。
sdk.ui.emptyState({ title, description, action })
sdk.ui.loadingState({ text: '正在同步…' })

Input / Field

Field 统一标签、必填标识、帮助文字和校验错误；输入控件保持相同高度与焦点环。

请输入有效的 HTTP 地址
const input = sdk.ui.input({ value })
const field = sdk.ui.field({ label: '播放入口', required: true, control: input })
field.setError('请输入有效的 HTTP 地址')

Select

统一下拉选择、键盘方向键、Enter、Space 与 Escape 行为。

sdk.ui.select({ value: 'auto', options, onChange })

Table

任务、媒体和日志列表的统一容器，支持固定表头、选择、空状态和自定义单元格。

作品状态进度
DLDSS-439已完成100%
SSPD-166处理中68%
sdk.ui.table({ columns, rows, rowKey: 'id', selectable: true,
  selectedKeys, onSelectionChange, onRowClick })

Settings Switch

设置页布尔值的唯一标准控件。

已启用
sdk.ui.settingsSwitch({ checked: true })

Setting Row

左侧名称与说明，右侧完整承载当前值和操作。

STRM 与播放

NOOR 播放入口由当前访问地址自动检测，也可以手动调整。
sdk.ui.settingRow({ label, description, control })

Path Input

对应 NOOR“设置 → 存储”的路径输入与目录弹窗。

本地 STRM incoming选择 NOOR 可以访问的本地目录。
sdk.ui.settingPath({ value, onBrowse })

Modal / Confirm

Modal 统一标题栏、固定操作区、焦点与滚动；危险操作使用异步 Confirm。

sdk.ui.modal({ title, content, footer, headerActions })
const approved = await sdk.ui.confirm({ title, message, danger: true })

Scrollbar

SDK 弹窗和 noor-plugin-scroll 自动获得统一滚动条。

element.classList.add('noor-plugin-scroll')
